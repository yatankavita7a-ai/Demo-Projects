# Demo Projects

A collection of my projects.

| Project | What it is | Stack |
|---|---|---|
| [CodeTrack](codetrack/) | Tracks a student's coding progress across LeetCode, GeeksforGeeks, CodeChef, Codeforces and GitHub in one dashboard, with leaderboards, a college dashboard and public portfolios. | Java, Spring Boot, Spring Security (JWT), JPA, PostgreSQL, HTML/CSS/JS |
| [Infinite Tower](infinite-tower/) | A 3D tower-climbing game with summons, a shop and save system. | Godot 4 (GDScript), shaders |
| [Campus Connect](campus-connect/) | A campus toolkit web app with assignment upload and download. | HTML, CSS, JavaScript (single page) |

Each folder has its own instructions. Campus Connect runs by opening `campus-connect/index.html` in a browser.
