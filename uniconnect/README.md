# UniConnect

A campus toolkit in a single HTML file: deadlines, notes exchange, faculty appointments,
assignments (upload and download), announcements and anonymous student feedback.
Use the **Demo role** switcher to act as a Student, Professor or Page Manager.

Open `index.html` in a browser; no install or server needed. Everything is saved in your browser:
data in `localStorage`, uploaded files (up to 10 MB each) in IndexedDB. **Reset demo data** in the
sidebar restores the sample content.

| Role | Can do |
|---|---|
| Student | Track deadlines, download notes and assignment briefs, request notes, book or cancel faculty slots, upload completed work, send anonymous feedback |
| Professor | Upload or remove notes, fulfil note requests, publish assignments with files, download submissions, add comments and feedback, add appointment slots, post announcements |
| Page Manager | Post and delete official announcements |

This is a front-end demo: data stays in one browser and isn't shared between users.
