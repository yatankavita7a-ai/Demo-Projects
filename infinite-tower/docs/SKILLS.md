# Hero skills

*Approved direction, 11 November 2026. This replaces the open questions in [HERO_SKILL_PROPOSAL.md](HERO_SKILL_PROPOSAL.md). Not built yet.*

## How skills work

- **Slots:** each hero can equip **1 active skill** and **up to 3 passive skills**. The active fires on its own key (planned: R) and has a cooldown. Passives are always on.
- **Each copy is separate:** a duplicate hero learns and equips skills on its own, matching how duplicates already keep independent progression.
- **Three ways to learn a skill:**
  1. **Levelling up.** Every hero learns their own **signature passive at Lv 5** and **signature active at Lv 10**. They also pick up one library skill suited to their class at Lv 3, 15 and 25.
  2. **Skill books found while exploring.** Hidden caches can hold a skill book instead of gear. A book teaches one library skill to one hero copy. Common and unusual books only, so the rare-find limit stays untouched.
  3. **The shop.** The Quartermaster sells some books, unlocked by floor, as part of the rotating stock you approved.
- **Who can use what:** signature skills belong to their hero. Library skills are tagged by class; a skill tagged "Any" fits everyone.
- **Bosses:** crowd-control effects (slow, root, pull, stun) are weaker against Guardians or turn into stagger damage, so no skill trivialises a boss.
